### What's new in 0.14.1
- **Copying now tells you it worked**: a small green **Copied** bubble pops up above the button when you copy a link (7/4/3 buttons, the upload button's Discord block, Volume jobs links) or the Process path. If the clipboard is busy (another app is holding it) it retries and shows a red bubble instead of failing silently

### Install / update
Already have AmqTool: **Help → Check for updates**.

New: download `AmqTool-Setup-v0.14.1.exe` below and run it (no admin needed; on *"Windows protected your PC"* click *More info → Run anyway*), or extract the zip anywhere you can write to. You also need ffmpeg: `winget install Gyan.FFmpeg`.
